# 五子棋 UI 界面布局优化设计文档

**日期:** 2026-05-19
**版本:** 1.0
**状态:** 已确认

---

## 1. 概述

本设计文档描述五子棋游戏前端界面的优化方案，以深色檀木风格为核心，打造经典棋盘游戏体验。

### 设计目标

- **视觉风格:** 经典棋盘 · 深色檀木
- **布局原则:** 极简留白，呼吸空间
- **交互体验:** 完整动效，增强游戏感

---

## 2. 色彩系统

### 主色板

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#1A1510` | 深木色，近乎黑色的沉稳感 |
| 棋盘 | `#2C1810` | 檀木色，深褐色带木纹 |
| 黑棋 | `#1A1A1A` | 纯黑，高对比度 |
| 白棋 | `#F5F5F5` | 象牙白，温润质感 |
| 强调色 | `#C9A86C` | 金色，用于胜利高亮 |
| 文字 | `#E8DCC8` | 米白色，柔和可读 |

### 辅助色

| 用途 | 色值 | 说明 |
|------|------|------|
| 悬停提示 | `rgba(201, 168, 108, 0.3)` | 金色半透明 |
| 最后落子光晕 | `rgba(201, 168, 108, 0.5)` | 脉冲提示 |
| AI 思考光晕 | `rgba(255, 215, 0, 0.4)` | 呼吸动画 |
| 胜利连线 | `#FFD700` | 金色闪烁 |

## 3. 布局结构

### 页面架构

```
┌─────────────────────────────────────┐
│                                     │
│                                     │
│            五 子 棋                  │  ← 标题，字体加粗，字间距加宽
│                                     │
│                                     │
│           ┌─────────┐               │
│           │         │               │
│           │         │               │
│           │  棋盘   │               │  ← 15×15 棋盘，居中显示
│           │         │               │
│           │         │               │
│           └─────────┘               │
│                                     │
│                                     │
│         [模式标签]                   │  ← 悬浮显示，底部内侧
│                                     │
│                                     │
└─────────────────────────────────────┘
```

### 间距规范

| 元素 | 间距值 | 说明 |
|------|--------|------|
| 标题上边距 | 60px | 大屏留白 |
| 标题与棋盘 | 40px | 清晰层次 |
| 棋盘与状态 | 24px | 紧凑但分离 |
| 按钮与底部 | 40px | 底部留白 |

### 棋盘尺寸

| 属性 | 值 | 说明 |
|------|-----|------|
| 棋盘格子大小 | 36px | 足够大的点击区域 |
| 棋盘总尺寸 | 540px (15×36) | 标准五子棋尺寸 |
| 棋子直径 | 28px | 格子约78% |
| 边框宽度 | 16px | 木质边框感 |

### 响应式策略

| 断点 | 行为 |
|------|------|
| < 600px | 棋盘缩放至屏幕90%宽度 |
| 600-900px | 棋盘540px，间距微调 |
| > 900px | 完整尺寸，极简留白 |

## 4. 组件设计

### 4.1 棋盘 (Board)

**外观:**
- 背景: 檀木色 `#2C1810` + CSS 木纹纹理
- 边框: 16px 实色边框，圆角 4px
- 网格线: 1px `rgba(0,0,0,0.3)` 色

**木纹纹理实现:**
```css
.board {
  background:
    linear-gradient(90deg, transparent 0%, rgba(0,0,0,0.03) 50%, transparent 100%),
    linear-gradient(180deg, rgba(0,0,0,0.05) 0%, transparent 30%, transparent 70%, rgba(0,0,0,0.05) 100%),
    var(--board-wood);
  background-size: 60px 100%, 100% 80px, 100% 100%;
}
```

### 4.2 棋子 (Cell/Piece)

**黑棋:**
- 颜色: `#1A1A1A`
- 效果: 微妙的内阴影模拟立体感
```css
.piece.black {
  box-shadow:
    inset 2px 2px 4px rgba(255,255,255,0.1),
    inset -2px -2px 4px rgba(0,0,0,0.3);
}
```

**白棋:**
- 颜色: `#F5F5F5`
- 效果: 微妙内阴影
```css
.piece.white {
  box-shadow:
    inset 2px 2px 4px rgba(255,255,255,0.8),
    inset -2px -2px 4px rgba(0,0,0,0.1);
}
```

### 4.3 状态显示 (Status)

**基础状态:**
- 文字: 白色带透明度
- 背景: 透明（悬浮在棋盘边缘内侧）

**获胜状态:**
- 文字: 金色 `#C9A86C`
- 效果: 轻微发光

**AI 思考状态:**
- 文字: 金色 `#FFD700`
- 动画: 呼吸光晕

### 4.4 模式选择 (ModeSelect)

**布局:**
- 垂直排列
- 主按钮大而突出
- AI 难度按钮横向排列

**按钮样式:**
- 背景: 半透明深色
- 边框: 1px 金色半透明
- 悬停: 背景加亮，边框金色

## 5. 动效规格

### 5.1 棋子落下动画

**时序:**
```
0ms     - 棋子出现在位置 (scale: 0.5, opacity: 0)
100ms   - 开始放大 (scale: 0.5 → 1.1)
200ms   - 超出目标 (scale: 1.1)
280ms   - 回弹至正常 (scale: 1.1 → 0.95 → 1)
400ms   - 动画结束
```

**缓动函数:**
```css
animation: pieceDrop 400ms cubic-bezier(0.34, 1.56, 0.64, 1);
```

### 5.2 最后落子光晕

**效果:** 棋子外圈金色脉冲
```css
@keyframes lastMoveGlow {
  0%, 100% {
    box-shadow: 0 0 0 3px rgba(201, 168, 108, 0.3);
  }
  50% {
    box-shadow: 0 0 0 5px rgba(201, 168, 108, 0.6);
  }
}
animation: lastMoveGlow 1.5s ease-in-out infinite;
```

### 5.3 AI 思考动画

**效果:** 棋子位置有呼吸光晕
```css
@keyframes aiThinking {
  0%, 100% {
    box-shadow: 0 0 10px rgba(255, 215, 0, 0.2);
  }
  50% {
    box-shadow: 0 0 20px rgba(255, 215, 0, 0.5);
  }
}
```

### 5.4 胜利连线动画

**效果:** 五子连线金色闪烁
```css
@keyframes winPulse {
  0%, 100% {
    box-shadow: 0 0 8px rgba(255, 215, 0, 0.8);
  }
  50% {
    box-shadow: 0 0 16px rgba(255, 215, 0, 1);
  }
}
animation: winPulse 0.8s ease-in-out infinite;
```

### 5.5 重新开始按钮

**入场动画:** 淡入 + 上移
```css
@keyframes fadeSlideUp {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
animation: fadeSlideUp 300ms ease-out;
```
